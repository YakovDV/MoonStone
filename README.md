# MoonStone

> **Work in progress** — MoonStone is an actively developed Unity project. The repository reflects the current state of development and will continue to change as gameplay, systems and content are added.

## Current systems

- Custom kinematic rover controller
- Ground detection and slope handling
- Collision solving and depenetration
- Runtime terrain track system
- Custom URP shaders and HLSL
- Lunar terrain and resource assets
- Rover animations and environment prototypes

## Tech

- Unity 2022.3.62f2
- C#
- Universal Render Pipeline (URP)
- Unity Input System
- ShaderLab / HLSL

## Status

Active development toward a playable release.
